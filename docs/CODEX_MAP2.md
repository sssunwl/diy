# Codex 工單：大地圖第二輪（SS 試用回饋）

先讀 `CLAUDE.md`、`src/scene.ts`、`src/main.ts`、`src/ui.ts`、`src/style.css`。只改 `src/`、`i18n/`。不改 Worker、`form.ts`、地圖資料，不做主題包或攤主自選，不要 commit。文字一律進 `i18n/*.json`。

## 1. 點攤位的流程（最重要）
現在：點佈景攤直接跳到申請頁，點地面時常誤觸；攤位資訊框蓋滿畫面。

改成：
- **命中判定用圖片實際像素**：用 sprite alpha（載入時建縮小的命中遮罩），透明處不算點到攤位，算點地面。人物也一樣
- **輕點攤位＝預覽框**：一個 DOM 小卡（不是 `#overlay`，地圖繼續動），像對話泡泡指向該攤，跟著攤位在畫面上的位置移動並夾在視窗內。外觀＝米白紙底約 92% 不透明、深棕細框、小尾巴，跟現有介面同系統
  - 有資料的攤：第一張商品圖縮圖、品牌名、類別、攤位牌文字。同時人物自動走過去
  - **人物走到攤前才開資訊框**，預覽框同時收起。玩家中途點別處就取消
  - 預覽框右上有關閉鈕；點地面也會收起
- **佈景攤／空位**：預覽框寫「這個位置還沒有攤主」，附一顆小按鈕「我要擺攤」。**只有按這顆按鈕才去申請頁**，地圖上任何點擊都不直接跳頁，人物也不用走過去
- 預覽框開著時再點另一攤，直接換內容

## 2. 攤位資訊框
- `.overlay` 背景改半透明（約 25% 深棕，不加模糊），地圖要看得到
- 手機：底部抽屜，高度上限 62vh，內容可捲動，往下拖或點外面關閉；攝影機把該攤移到抽屜上方可見處
- 電腦：靠右的側欄，寬約 420px，一樣能看到地圖
- 只影響攤位資訊框，教學、角色選擇照舊置中

## 3. 攤名標籤重新設計
現在是白底方塊加無襯線字，壓在攤位上，跟畫面不搭。
- 改成畫面內的「小木牌」：深棕 1.5px 框、米白紙底、圓角 3px、下方一個小掛鉤線連到棚頂中央，字用介面同一套字型 12px 深棕，尺寸不隨縮放變動
- 只顯示離玩家最近的 3 攤＋預覽中的那攤，淡入淡出 150ms，彼此重疊時較遠的不畫。縮放 < .6 全部不畫
- 不要標到佈景攤

## 4. 手機操作
- canvas 要 `touch-action:none`，頁面不能被捲動或雙指放大
- 手機預設縮放 .8，一次看到更多攤
- **路線拉直**：BFS 結果做視線平滑（string pulling，用 mask 檢查），人物斜著走，不要 L 形轉彎
- 點地面時畫一個淡出的目的地標記（小圓圈漣漪）
- 拖動門檻手機放大到 10px，避免輕點被當成拖動
- 底部控制列改精簡：手機只留「下一攤」「全圖」「找攤位」三顆，高度 48px、貼齊安全區 `env(safe-area-inset-bottom)`。上一條街／下一條街移除（地圖本來就連在一起），`change()` 保留給街道標籤使用：點左上街名切換
- 頂部街名與「逛過」合併成一顆膠囊放左上，手機上不佔兩個角
- 「全圖」再按一次回到跟隨玩家的預設縮放；全圖模式要把頂欄和控制列的高度算進去，地圖置中，避免上下露出色帶（外圍用 `fill` 色並同樣受調光影響）
- 電腦版控制列可保留現有版面，但同樣移除上一條街／下一條街

## 5. 夜晚攤位太暗
現在只有地面燈光圖，棚內也暗。照 `tools/mock_map.py` 的 `build()` 物件亮度做法：
- 夜晚 ambient 由 (.19,.23,.42) 調到 (.27,.30,.48)；傍晚不變
- 載入時替每張攤位 sprite 做一張「燈光遮罩」canvas：用 sprite 的 alpha 當形狀，亮度由上到下漸變 `clamp(.45 + y/h*1.9, 0, 1)`，暖色同現有 warm
- 每幀在 grade 畫布上用 `lighter`，把視窗內攤位的遮罩畫上去。有攤主或佈景攤強度 1；`empty` 強度 .12，讓空攤一眼看得出來
- grade 畫布解析度改為視窗的 1/2，邊緣才不會糊成一片；每幀只畫視窗內的
- 驗收：夜晚放大看，攤位商品的顏色要認得出來，棚內明顯比地面亮，棚頂較暗
