# 趁墟等角素材第一批 — 部分通過，尚未完成驗收

使用內建 image_gen（imagegen 技能），共呼叫 19 次，涵蓋六張素材表。六張均有重生：stalls_a 共 4 次、stalls_b 共 3 次、ground_props 共 3 次、buildings 共 2 次、walk 共 3 次、portraits 共 4 次。初次之外合計 13 次重生／版面修正。失敗版本未當成正式素材輸出。

`src/` 有六張 2048×2048 PNG。工具實際回傳的原生尺寸都是 1254×1254，這些檔案是放大封裝，並非原生 2K；人物像素表以 nearest-neighbor 放大，其餘用 Lanczos。人物與地磚仍不合格，保存的是供排查的試圖，不能視為正式來源。

目前輸出 28 / 80 件：12 攤位、12 道具、4 建築。`public/art/contact.html` 顯示所有已輸出的透明 WebP、名稱與像素錨點。`public/art/manifest.json` 只收錄已輸出的素材。錨點座標相對於裁掉透明邊後的圖，以 alpha >= 128 的最底列左右端中點估算，地磚則取中心；錨點仍需在實際遊戲尺度覆核。

未通過的 52 件：4 塊地磚的菱形比例不精確（多次重生仍約 1.8 或 2.2，未硬改幾何）；36 格 walk 的跨列、腳底位置、重複步態及背向方向；12 格 portraits 的不等高排列、跨格及服裝漂移。`qa/rejections.json` 明確封鎖這些素材，避免半截人物或不合格地磚進 manifest。既有圖必須重生並人工確認後，才能移除對應封鎖。

執行 `python3 tools/slice.py` 重新切圖，只需要系統 Pillow，不需 npm 套件。只要有拒絕項，程式仍輸出安全素材與檢查頁，但會回傳 exit code 2，表示整批尚未驗收完成。完整尺寸、格內留白與幾何檢查紀錄在 `public/art/qa.json`。目前的留白檢查以 8% 為門檻，地磚另外允許 90% 寬度所需的 5% 邊距；人物增加腳底 85% 與同列高度檢查。步態、角色辨識與文字仍需人工視覺檢查。

素材以純洋紅做色鍵，切圖涵蓋混色邊緣的軟透明與 1px 去色邊，輸出 lossless WebP。已檢查透明、尺寸與錨點範圍，並用合成色鍵邊緣驗證去背和錨點計算。沒有改動 src/、worker/、現有程式、沒有安裝套件、沒有 commit。
